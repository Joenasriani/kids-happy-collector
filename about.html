Happy Collector — Good Habits Adventure

Play the game · Itch.io release · Source repository

What it is

Happy Collector is a 20-level 3D browser platformer created for the UAE children’s event project.

Game structure

platform movement → collect Good Habit blocks → avoid or stomp Bad Habit blocks → navigate level obstacles → reach the exit → advance

The player controls a yellow cube across floating platforms. The game includes moving platforms, cracking glass sections, Good Habit collectibles, Bad Habit obstacles/enemies and a level exit.

Levels

The implemented game contains 20 levels. Level 20 is the final level.

Event project context

This game belongs to the same kids-* set created for the UAE children’s event project.

Public builds

The Vercel deployment and itch.io release expose the same Happy Collector game lineage represented by this repository.

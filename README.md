# Happy Collector: Good Habits Adventure

**Status:** original 3D browser platform game  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Happy Collector: Good Habits Adventure is a 3D browser platform game where a smiling yellow cube collects Good Habit blocks, avoids or stomps Bad Habit blocks, crosses floating islands and cracking glass bricks, and reaches the level exit.

## Game identity

Historical short name: **Happy Collector**.

Happy Collector and Happy Collector: Good Habits Adventure are the same game lineage.

## Current build

The repository tracks the browser release candidate prepared for itch.io, with twenty playable levels, local Three.js files, music and sound effects, and desktop/mobile controls.

## Controls

Desktop: A/D or arrow keys to move; Space or Up Arrow to jump.

Mobile: on-screen movement and jump controls.

Existing branches, release packages and historical files are retained as development history.

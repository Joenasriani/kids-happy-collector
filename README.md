# Happy Collector — Good Habits Adventure

Play: https://kids-happy-collector.vercel.app/

Itch.io: https://joenasr.itch.io/happy-collector

Happy Collector is a 20-level 3D browser platformer. The player controls a yellow cube across floating platforms, collects yellow **Good Habit** blocks, avoids or stomps red **Bad Habit** blocks, uses moving platforms, crosses cracking-glass sections, and reaches the level exit.

## How it plays

**move and jump → collect Good Habit blocks → avoid or stomp Bad Habit blocks → navigate obstacles → reach the exit → advance**

The current game implements 20 levels. Levels 11–20 have authored level identities, and Level 20 is the final level.

## Controls

### Desktop

- `A / D` or `Left / Right Arrow` — move
- `Space` or `Up Arrow` — jump

### Mobile

- on-screen left/right controls — move
- on-screen jump control — jump

## Implementation

- `index.html` — playable game
- `libs/` — local Three.js runtime and license
- `music/` — music assets
- `sfx/` — sound effects
- `fonts/` — local fonts
- `docs/` — level and QA documentation

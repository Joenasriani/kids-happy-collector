# Happy Collector

A browser-based 3D platformer game. Collect yellow good-emotion blocks, avoid or stomp red bad-emotion blocks, and reach the door through 10 levels.

## Run locally
Open `index.html` in a browser, or serve the folder with a local static server.

## Included assets
- `music/` - level music tracks
- `sfx/` - cinematic wind sound effect
